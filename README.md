# Fast React Pizza Co.

This React application uses [Vite](https://vite.dev/) for local development and production builds.

## Available Scripts

In the project directory, you can run:

### `npm run dev`

Starts the local development server.

### `npm run build`

Creates an optimized production build in `dist/`.
